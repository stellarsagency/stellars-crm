# Stellars CRM - AI Cold Calling System

## Quick Start
1. Double-click `start.bat`
2. Open browser: http://localhost:3000
3. Login: admin / admin123

## Default Accounts
- **Admin:** admin / admin123 (full access)
- **Caller:** Create in Settings → User Management

## Features
- 📊 Dashboard with stats
- 📋 Pipeline (Kanban view)
- 👥 Leads management
- 🔍 Lead Finder (scrapes Google Maps)
- 📞 AI Cold Calling (Bland.ai)
- 📅 Meetings
- 🔔 Follow-ups
- 👤 Sales Reps
- 🗺️ Map view

## Caller Permissions
Callers can see:
- Dashboard
- Pipeline
- Leads
- Meetings
- Follow-ups
- Activity

Callers cannot see:
- AI Calling
- Lead Finder
- Sales Reps
- Settings

## Niche Targeting
- Pressure Washing
- Auto Detailing
- Painting
- Pest Control
- Fence
- Landscaping
- Cleaning
- Pool Service

## City Options
- Full States (30 cities each)
- Major Cities (10-30 suburbs)
- Small Cities (20 cities each)

## Goal-Based Scraping
- No Website leads
- Outdated Website leads
- All leads

## Tech Stack
- Backend: Express.js + sql.js
- Frontend: Vanilla JS
- Scraper: maps-scrapper (Playwright)
- Database: SQLite (sql.js)
